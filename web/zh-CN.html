Flatpak 版 Google Antigravity

Google Antigravity 的非官方 Flatpak 软件源,带 GPG 签名。定时工作流会构建每个上游新版本,你用 flatpak update 更新即可。

安装

需要 Flatpak 和 Flathub 软件源,运行时由 Flathub 提供。

软件源

只需添加一次软件源,之后更新会和其他 Flatpak 应用一起到达。

flatpak remote-add --if-not-exists antigravity https://jhuang6451.github.io/antigravity-flatpak/antigravity.flatpakrepo
flatpak install antigravity com.google.Antigravity
flatpak run com.google.Antigravity

.flatpakref 文件

下载文件后用 GNOME Software 或 KDE Discover 打开,也可以执行下面的命令。如果还没有 Flathub,它会一并添加,用来获取运行时。

flatpak install antigravity.flatpakref
下载 .flatpakref

离线安装包

从最新发布页下载 com.google.Antigravity.flatpak。安装包不会收到更新。

flatpak install com.google.Antigravity.flatpak
打开最新发布页

更新

执行这条命令,或者交给软件中心。

flatpak update com.google.Antigravity

权限

默认沙箱的范围较大。安装前请先了解这三点。

整个家目录

应用可以读写家目录里的所有内容,包括 ~/.ssh 和 ~/.gnupg。Antigravity 的智能体也可以。

宿主机上的命令

org.freedesktop.Flatpak 允许 flatpak-spawn --host,即在沙箱外执行任意命令。所以沙箱不是安全边界。

SSH agent

--socket=ssh-auth 让应用能使用 agent 里加载的所有密钥。

完整列表

--socket=wayland--socket=fallback-x11--share=ipc
显示。有 Wayland 用 Wayland,否则用 X11。ipc 用于 X11 共享内存。
--share=network

--device=dri

收紧或放宽权限

用户覆盖优先于清单。在终端里执行下面的命令。

收紧

去掉 home 后,应用看不到 ~/.gitconfig、~/.ssh 和 ~/.local/bin 里的工具,需要的话再单独加回来。

# 只开放一个项目目录,不开放整个 $HOME
flatpak override --user --nofilesystem=home --filesystem=~/Projects com.google.Antigravity

# 去掉宿主机命令执行
flatpak override --user --no-talk-name=org.freedesktop.Flatpak com.google.Antigravity

# 去掉 SSH agent
flatpak override --user --nosocket=ssh-auth com.google.Antigravity

# 撤销所有覆盖
flatpak override --user --reset com.google.Antigravity

放宽

能访问 Docker 套接字就等于拥有宿主机的 root 权限。device=all 会暴露所有设备节点。

# /dev/kvm,用于 QEMU 和 Android 模拟器
flatpak override --user --device=kvm com.google.Antigravity

# USB 和串口设备
flatpak override --user --device=all com.google.Antigravity

# 外接磁盘和其他顶层路径
flatpak override --user --filesystem=/mnt --filesystem=/run/media --filesystem=/media com.google.Antigravity
flatpak override --user --filesystem=/srv --filesystem=/opt com.google.Antigravity

# Podman 和 Docker 套接字
flatpak override --user --filesystem=xdg-run/podman com.google.Antigravity
flatpak override --user --filesystem=/run/docker.sock com.google.Antigravity

已知限制

默认权限下无法使用的功能,以及对应的处理办法。

  • 设备没有 /dev/kvm、USB 和串口。刷写硬件、通过 USB 使用 adb、硬件加速的模拟器,都无法在沙箱内运行。
  • 家目录以外的路径/mnt、/media、/run/media、/srv、/opt 和 /var/www 看不到。
  • 容器套接字Docker 和 Podman 的套接字看不到,授权后才能访问。
  • Fedora Atomic 上写死的 /home 路径家目录是 /var/home/<用户名>,沙箱里没有 /home 符号链接,所以 /home/<用户名>/... 会失败。请改用 $HOME 或 ~。
  • 宿主机工具装在宿主机系统目录里的程序不在 PATH 中。装在家目录下的工具可以用。其他情况请用 flatpak-spawn --host。
  • 内置更新器在只读的应用目录中的表现尚未测试。请通过 Flatpak 更新,应用内的更新提示可以忽略。
  • 架构仅 x86_64,因为上游没有发布其他架构的 Linux 版本。
  • 上游不提供校验和CI 会记录自己下载的压缩包的 SHA256。这能把构建固定在那份文件上,但不能证明它和 Google 想发布的内容一致。
