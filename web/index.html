Google Antigravity IDE

下一代智能体编程集成开发环境 (Agentic IDE)。基于 Flatpak 沙箱化打包，一键安装，无缝跨主流 Linux 发行版运行。

一键安装 (.flatpakref) 终端命令安装

终端快速安装（推荐）

只需添加一次仓库，即可享受 Flatpak 官方标准的软件包管理与全自动后台更新：

终端命令行安装 
# 1. 添加 Antigravity 软件源
flatpak remote-add --if-not-exists antigravity https://jhuang6451.github.io/antigravity-flatpak/antigravity.flatpakrepo

# 2. 安装 Antigravity IDE
flatpak install -y antigravity com.google.Antigravity

# 3. 运行 Antigravity
flatpak run com.google.Antigravity
日常更新命令 
# 检查并更新到最新版本
flatpak update com.google.Antigravity

GitHub Actions 每 6 小时监控 Google 官方分发端。检测到新版本后自动计算校验和、构建 OSTree 增量镜像并发布。

基于 FreeDesktop 运行时沙箱保护，同时配置 --filesystem=host 与密钥环通道，无缝访问本地项目源码与环境。
